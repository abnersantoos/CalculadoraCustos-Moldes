# 🧮 Calculadora de Orçamento e Custo de Ferramentais (Injeção Plástica)

Ferramenta desenvolvida em **Python** para estimar custos industriais de novos moldes de injeção plástica com base em taxas horárias, desgaste de máquina, cubagem e componentes padronizados.

## 📌 Como Usar
1. Instale o Python 3.x.
2. Altere os valores dentro da classe `ParametrosFerramental` no arquivo `orcamento_ferramental.py` conforme a especificação do novo molde (dimensões, tipo de aço, câmara quente e horas estimadas).
3. Execute o script:
   ```bash
   python orcamento_ferramental.py
